# VoltLedger ⚡ (v2.2.0)

**VoltLedger** — интуитивный, производительный и автономный журнал учета зарядок и расходов для владельцев электромобилей (EV), разработанный на Jetpack Compose и Material Design 3.

---

## 🚀 Что нового в версии 2.2.0

1. **Простое резервное копирование на Google Диск в 1 клик:**
   * Больше никаких сложных токенов GitHub и настроек — теперь резервную копию можно сохранить прямо в личный **Google Диск** или хранилище телефона через стандартный системный проводник Android.
   * Восстановление данных с Google Диска в 1 клик — приложение само считывает выбранный `.json` файл и обновляет базу.
   * Нативная кнопка **«Поделиться файлом»** (Android Sharesheet: сохранение на Диске, отправка в Telegram, Gmail, Nearby Share).

2. **Привязка E-mail и отправка копии на почту:**
   * В настройках профиля добавлен блок привязки основного E-mail адреса.
   * Отправка резервной копии базы в 1 клик на ваш E-mail для надёжного архива.

3. **Инструкция по лёгкой смене телефона:**
   * Интерактивный диалог в настройках с простыми шагами: как перенести авто, зарядки и тарифы на новый смартфон за считанные секунды.

4. **Мягкое неоновое свечение и визуальный апгрейд:**
   * Внутреннее радиальное свечение в блоке расхода с мягким переходом к границам.
   * Легкая светящаяся тень для цифр среднего расхода энергии.

5. **Официальный журнал изменений ([CHANGELOG.md](./CHANGELOG.md)):**
   * Все релизы, улучшения и исправления теперь строго структурированы по стандарту Keep a Changelog.

6. **Обновление версий:**
   * `versionCode = 6`, `versionName = "2.2.0"`.

## 🏷️ Тег для публикации на GitHub

Для создания релиза в GitHub используйте следующий тег:

```bash
v2.2.0
```

> **Автоматическая сборка:** При пуше тега `v2.2.0` сработает GitHub Actions workflow (`.github/workflows/build-and-release.yml`), который скомпилирует APK и прикрепит готовый файл **`VoltLedger-v2.2.0-debug.apk`** прямо к релизу на GitHub.

### Команды Git для быстрой публикации:

```bash
# 1. Зафиксировать изменения
git add .
git commit -m "Release v2.2.0: Google Drive 1-tap backup, email sync, soft glow styling, CHANGELOG"

# 2. Создать тег новой версии
git tag v2.2.0

# 3. Отправить ветку и тег на GitHub
git push origin main --tags
```

## 📱 Ключевые возможности приложения

* 🔋 **Двухэтапный учет сессий:** Быстрый запуск сессии при подключении к станции или домашней розетке в 1 тап, и точное завершение с учетом отданной энергии, потерь на зарядку и стоимости.
* ⚡ **Операторы и ночные тарифы:** Поддержка операторов Malanka, BatteryFly, Evika, Fora, домашней розетки и кастомных сетей. Автоматическое применение льготных ночных тарифов.
* ⏱️ **Учёт штрафов и платного простоя:** Расчет стоимости превышения лимита времени нахождения на ЭЗС.
* 📊 **Глубокая аналитика:** Стоимость 100 км пробега, сравнение реального расхода с паспортным WLTP, динамика затрат по месяцам.
* 💾 **Резервное копирование:** Экспорт и импорт базы данных в форматы JSON и CSV.
* 🔒 **Безопасность:** Защита входа PIN-кодом и биометрией.
