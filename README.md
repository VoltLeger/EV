# VoltLedger ⚡ (v2.5.6)

**VoltLedger** — интуитивный, производительный и автономный журнал учёта зарядок и расходов для владельцев электромобилей (EV), разработанный на Jetpack Compose и Material Design 3.

---

## 🚀 Что нового в версии 2.5.6

### 1. ☀️ Светлая тема оформления (Light Theme)
* Добавлена полноценная светлая тема с аккуратным матовым стеклом, светлым фоном и глубокими контрастными акцентами для комфортного использования приложения при ярком солнечном свете.
* Все компоненты — фон `LiquidGlassBackground`, карточки `VoltCard`, навигационная панель, центральный блок расхода и диаграммы — автоматически адаптируются под выбранную тему.

### 2. 🎨 Цветные темы наподобие визитки после зарядки (Postcard Color Themes)
* В настройках оформления (раздел «Внешний вид») теперь можно выбрать фирменные стили из открыток/визиток:
  * 🌿 **Эко Изумруд (Eco Emerald):** глубокие изумрудные тона (#042017) и мятный неон (#10B981, #06D6A0).
  * 🌅 **Закатный Драйв (Sunset Drive):** тёплые коралловые (#F43F5E) и янтарные (#F59E0B) тона заката.
  * 🌌 **Космос (Deep Space):** глубокий космический индиго (#070B1E) и небесно-лазурный (#38BDF8, #818CF8).
  * ⚡ **Кибер Неон (Cyber Neon):** классическая тёмная неоновая тема.

### 3. 🚗 Обновление пробега в карточке авто и защита ввода зарядок
* **Мгновенное обновление одометра:** При завершении или начале зарядки одометр автомобиля в базе данных обновляется напрямую и сразу же отражается в карточке авто («Паспорт автомобиля») и на главном экране.
* **Защита полей от сброса:** В окне «Добавить зарядку» введённые пользователем значения уровня заряда, одометра и стоимости зафиксированы и не сбрасываются фоновыми событиями.
* **Интеллектуальный расчёт расхода (правило 200 км):** Расход за последние 2 зарядки отображается, если пробег превышает 200 км; при частых коротких подзарядках алгоритм автоматически объединяет историю до репрезентативного пробега.
* **Плавная кривая расхода в статистике:** Снизу — даты месяца, сверху — показатели расхода и плавная кубическая кривая Безье.

## 🏷️ Тег для публикации на GitHub

Для создания нового релиза в GitHub используйте тег:

```bash
v2.5.6
```

> **Автоматическая сборка:** При пуше тега `v2.5.6` сработает GitHub Actions workflow (`.github/workflows/build-and-release.yml`), который скомпилирует APK и прикрепит готовый файл **`VoltLedger-v2.5.6-debug.apk`** прямо к релизу на GitHub.

### Команды Git для быстрой публикации:

```bash
# 1. Зафиксировать все изменения
git add .
git commit -m "Release v2.5.6: add light theme and colorful postcard themes (Eco Emerald, Sunset Drive, Deep Space), theme-adaptive UI"

# 2. Создать тег новой версии
git tag v2.5.6

# 3. Отправить ветку и тег на GitHub
git push origin main --tags
```
