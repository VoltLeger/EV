# VoltLedger ⚡ (v2.3.1)

**VoltLedger** — интуитивный, производительный и автономный журнал учёта зарядок и расходов для владельцев электромобилей (EV), разработанный на Jetpack Compose и Material Design 3.

---

## 🚀 Что нового в версии 2.3.1

### 1. ⚡ Гибкая настройка тарифов «Домашней зарядки» и быстрый переключатель
* **3 быстрые кнопки выбора тарифа в окне запуска («Стандарт», «2-зонный», «3-зонный»):** В окне быстрого запуска домашней зарядки пользователь может в 1 клик переключиться между стандартным тарифом (активным всегда), 2-зонным (день/ночь) или 3-зонным тарифом с моментальным пересчётом ориентировочной стоимости.
* **Подсказка и сохранение последнего показания счётчика:** Домашний счётчик электроэнергии теперь сохраняет последнее введенное значение (отдельно в хранилище). В окне домашней зарядки отображается подсказка с предыдущим числом, по нажатию на которую значение мгновенно подставляется в поле ввода.
* **Предупреждение о ненастроенных тарифах:** При первом нажатии на кнопку **«Домашняя зарядка»** приложение проверяет наличие сохранённых настроек. Если тарифы ещё не настроены, пользователю показывается понятный диалог с предложением перейти в Настройки либо продолжить со стандартным тарифом.
* **Поддержка всех типов домашних тарифов:**
  * **Одноставочный (стандартный):** по умолчанию **0.36** за 1 кВт·ч (настраивается под любой регион/страну).
  * **Двухзонный (день / ночь):** ночной период с **23:00 до 06:00** со сниженной стоимостью (по умолчанию **0.1822** за 1 кВт·ч).
  * **Трёхзонный дифференцированный тариф (галочка/переключатель):**
    * **Пиковый (максимальных нагрузок):** с 17:00 до 23:00 — **0.5467** за 1 кВт·ч.
    * **Ночной (минимальных нагрузок):** с 23:00 до 06:00 — **0.1822** за 1 кВт·ч.
    * **Полупиковый (остальное время):** с 06:00 до 17:00 — **0.2126** за 1 кВт·ч.
* **Автоматическое определение тарифа по системному времени:** Приложение берёт системное время смартфона и мгновенно подсказывает действующий тариф, рассчитывая точную прогнозную стоимость до 100% заряда батареи.

### 2. 🚗 Всегда актуальный пробег (Одометр)
* **Поле ввода пробега при завершении зарядки:** В экране завершения зарядки (`FinishChargingScreen`) добавлено поле для фиксации текущего показания одометра автомобиля.
* **Автоматическое обновление пробега на главном экране:** В верхней панели автомобиля на Главном экране (`HomeScreen`) всегда динамически отображается самый свежий пробег автомобиля, который мгновенно обновляется после завершения любой зарядки или добавления расхода/услуги.

### 3. 🧹 Полная оптимизация и удаление неработающего кода
* Полностью удалены невостребованные и вызывавшие ошибки компоненты биометрии/пин-кода (`BiometricHelper`, фрагменты `biometric-ktx`), облегчив кодовую базу, убрав лишние разрешения и фоновые слушатели жизненного цикла.
* Оптимизированы ViewModel и DataStore, улучшена отзывчивость интерфейса.

### 4. 🔑 Решение конфликта установки («Конфликт с другим пакетом»)
* При обновлении со старых сборок (2.2.1 / 2.3) ошибка `INSTALL_FAILED_UPDATE_INCOMPATIBLE` ("Файл установки конфликтует с другим пакетом") возникает из-за несовпадения сертификата подписи (когда старый APK был подписан одним ключом, а новый собрался локальным/новым сгенерированным).
* **Для бесшовного обновления:** Все релизные сборки в репозитории подписаны постоянным ключом `debug.keystore`, зафиксированным в проекте.
* **Если на устройстве уже стоит версия с другим сертификатом:** Android из соображений безопасности системы запрещает прямую замену приложения с другим ключом подписи. Чтобы установить обновление, сделайте резервную копию данных (в 1 клик на Google Диск или отправьте на E-mail в Настройках), удалите старую сборку с телефона и установите `VoltLedger-v2.3.1-debug.apk`. Все последующие обновления будут устанавливаться поверх без удаления!

## 🏷️ Тег для публикации на GitHub

Для создания нового релиза в GitHub используйте тег:

```bash
v2.3.1
```

> **Автоматическая сборка:** При пуше тега `v2.3.1` сработает GitHub Actions workflow (`.github/workflows/build-and-release.yml`), который скомпилирует APK и прикрепит готовый файл **`VoltLedger-v2.3.1-debug.apk`** прямо к релизу на GitHub.

### Команды Git для быстрой публикации:

```bash
# 1. Зафиксировать все изменения
git add .
git commit -m "Release v2.3.1: home charging tariff configuration, odometer tracking on main screen & finish charge, remove auth clutter, bump to v2.3.1"

# 2. Создать тег новой версии
git tag v2.3.1

# 3. Отправить ветку и тег на GitHub
git push origin main --tags
```
