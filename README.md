# VoltLedger ⚡ (v2.5.5)

**VoltLedger** — интуитивный, производительный и автономный журнал учёта зарядок и расходов для владельцев электромобилей (EV), разработанный на Jetpack Compose и Material Design 3.

---

## 🚀 Что нового в версии 2.5.5

### 1. 🚗 Мгновенное обновление пробега в карточке авто и базе данных
* **Синхронизация карточки авто:** Исправлена проблема, при которой пробег в карточке автомобиля не обновлялся после завершения или запуска зарядки. Теперь при вводе одометра в любой зарядке (DC, AC, Домашняя или ручное редактирование) показания автомобиля в базе данных обновляются напрямую и немедленно отражаются в карточке автомобиля («Паспорт автомобиля»), на главном экране и в гараже настроек.
* **Отображение текущего пробега в паспорте авто:** В окне паспорта автомобиля добавлена специальная строка «Текущий пробег», подсвеченная акцентным цветом и всегда показывающая актуальный пробег с учётом последних зарядок.

### 2. 🛡️ Полная защита полей в окне «Добавить зарядку» от сброса значений
* **Изоляция введённых данных (`rememberSaveable` + флаги редактирования):** Устранена проблема, когда в окне добавления зарядки быстро пропадали введённые значения.
* Поля уровня заряда (SoC %), одометра и стоимости за кВт·ч теперь защищены от перезаписи фоновыми потоками и пересчётами операторов. Если пользователь начал ввод или изменил любое поле, значения никогда не сбрасываются и не возвращаются к пустым/стандартным, пока пользователь сам не закроет окно или не нажмёт «Запустить зарядку».

### 3. 📈 Интеллектуальный расчёт среднего расхода (правило 200 км)
* **Адаптивная агрегация коротких зарядок:** Если расстояние между двумя последними зарядками составляет более 200 км, рассчитывается точный расход за последние 2 сессии («СРЕДНИЙ РАСХОД ЗА 2 ПОСЛЕДНИЕ ЗАРЯДКИ»).
* Если же пользователь проехал меньше 200 км (например, частые подзарядки по несколько процентов), алгоритм незаметно для пользователя аккумулирует историю зарядок назад во времени до накопления репрезентативного пробега (>= 200 км), рассчитывая точный физический расход энергии без шума и погрешностей коротких поездок.

### 4. 📊 Новая диаграмма динамики расхода в разделе «Статистика»
* **Плавная кривая расходов:** В разделе статистики на главном экране обзора добавлена интерактивная диаграмма с неоновой кубической кривой Безье (`CubicTo`), визуализирующая изменение расхода энергии.
* **Снизу — даты месяца:** По горизонтальной оси отображаются даты совершённых зарядок в течение месяца.
* **Сверху — показатели расхода:** Отображаются средний расход крупным шрифтом с неоновым свечением, а также максимальное и минимальное зафиксированное значение за период.

## 🏷️ Тег для публикации на GitHub

Для создания нового релиза в GitHub используйте тег:

```bash
v2.5.5
```

> **Автоматическая сборка:** При пуше тега `v2.5.5` сработает GitHub Actions workflow (`.github/workflows/build-and-release.yml`), который скомпилирует APK и прикрепит готовый файл **`VoltLedger-v2.5.5-debug.apk`** прямо к релизу на GitHub.

### Команды Git для быстрой публикации:

```bash
# 1. Зафиксировать все изменения
git add .
git commit -m "Release v2.5.5: fix car card odometer update, protect add charge inputs from reset, intelligent 200km consumption rolling window, smooth monthly consumption curve chart in statistics"

# 2. Создать тег новой версии
git tag v2.5.5

# 3. Отправить ветку и тег на GitHub
git push origin main --tags
```
