# VoltLedger ⚡ (v2.1.0)

**VoltLedger** — интуитивный, производительный и автономный журнал учета зарядок и расходов для владельцев электромобилей (EV), разработанный на Jetpack Compose и Material Design 3.

---

## 🚀 Что нового в версии 2.1.0

1. **Расчёт затраченного электричества по электросчётчику при завершении зарядки:**
   * В меню завершения сессии (особенно для домашней розетки) добавлен отдельный блок ввода показаний электросчётчика: **Начальные (кВт·ч)** и **Конечные (кВт·ч)**.
   * Если начальные показания были введены при старте домашней зарядки в 1 тап — они автоматически подставляются в поле начальных показаний.
   * При вводе конечных показаний приложение мгновенно вычисляет дельту (`Конечные - Начальные`) и автоматически заполняет объём израсходованного электричества и итоговую стоимость по тарифу.
   * Показания счётчика (`Счётчик: X → Y (Z кВт·ч)`) автоматически сохраняются в комментарий к сессии и отображаются в истории.

2. **Цифровой паспорт электромобиля (Car Passport):**
   * Расширенная карточка технических характеристик авто: полезная и полная ёмкость аккумулятора (кВт·ч), химия батареи (LFP, NMC, NCA), тип привода (RWD, FWD, AWD), заводской паспортный расход WLTP (кВт·ч/100 км), размерность шин, VIN-номер и заметки.
   * Автоматический расчёт программного буфера ёмкости батареи.
   * Прямое сравнение реального расхода с паспортным WLTP.

3. **Оптимизация и разгрузка главного экрана:**
   * Убран дублирующий блок «Зал славы» по центру экрана для обеспечения чистого и компактного интерфейса.
   * Профиль пилота, уровни опыта и награды по-прежнему доступны в один клик через аватар в правом верхнем углу шапки.

4. **Обновление версий:**
   * `versionCode = 5`, `versionName = "2.1.0"`.

## 🏷️ Тег для публикации на GitHub

Для создания релиза в GitHub используйте следующий тег:

```bash
v2.1.0
```

> **Важно:** При создании тега `v2.1.0` (или публикации GitHub Release с этим тегом) автоматически сработает GitHub Actions workflow (`.github/workflows/build-and-release.yml`), который скомпилирует APK и прикрепит готовый файл **`VoltLedger-v2.1.0-debug.apk`** прямо к релизу на GitHub.

### Команды Git для быстрой публикации:

```bash
# 1. Зафиксировать изменения
git add .
git commit -m "Release v2.1.0: Meter calculations for home charging, car passport, UI cleanup"

# 2. Создать тег
git tag v2.1.0

# 3. Отправить ветку и тег на GitHub
git push origin main --tags
```

## 📱 Ключевые возможности приложения

* 🔋 **Двухэтапный учет сессий:** Быстрый запуск сессии при подключении к станции или домашней розетке в 1 тап, и точное завершение с учетом отданной энергии, потерь на зарядку и стоимости.
* ⚡ **Операторы и ночные тарифы:** Поддержка операторов Malanka, BatteryFly, Evika, Fora, домашней розетки и кастомных сетей. Автоматическое применение льготных ночных тарифов.
* ⏱️ **Учёт штрафов и платного простоя:** Расчет стоимости превышения лимита времени нахождения на ЭЗС.
* 📊 **Глубокая аналитика:** Стоимость 100 км пробега, сравнение реального расхода с паспортным WLTP, динамика затрат по месяцам.
* 💾 **Резервное копирование:** Экспорт и импорт базы данных в форматы JSON и CSV.
* 🔒 **Безопасность:** Защита входа PIN-кодом и биометрией.
