# VoltLedger ⚡ (v2.5.4)

**VoltLedger** — интуитивный, производительный и автономный журнал учёта зарядок и расходов для владельцев электромобилей (EV), разработанный на Jetpack Compose и Material Design 3.

---

## 🚀 Что нового в версии 2.5.4

### 1. 🛡️ Полная защита введённых данных в окне зарядки от сброса и закрытия
* **Исключён автоматический сброс данных:** Исправлена проблема, когда введённые значения в окне домашней зарядки сбрасывались через короткое время из-за фоновых обновлений состояния. Теперь введённые пользователем показания батареи, одометра и счётчика надёжно сохраняются в памяти диалога и никогда не перезаписываются самопроизвольно.
* **Защита от случайного закрытия по клику вне диалога (`dismissOnClickOutside = false`):** Окно быстрой зарядки больше не закроется случайно при неосторожном касании за пределами карточки. Закрытие происходит исключительно по кнопке «Отмена», системной кнопке «Назад» или по нажатию «Запустить».
* **Устойчивость ввода одометра:** В экране `StartChargingScreen` поля одометра и уровня заряда изолированы от фоновых пересчётов и сохраняют то, что набирает пользователь.

### 2. 📢 Официальный Telegram-канал проекта
* **Интеграция в «Профиль пользователя»:** В разделе «Профиль Пилота и Награды» добавлена карточка перехода в официальный Telegram-канал проекта [**@VoltLeger**](https://t.me/VoltLeger) для получения новостей, анонсов обновлений и общения с сообществом.
* **Ссылка в Настройках:** В разделе «О разработчике» и футере экрана настроек также добавлена быстрая ссылка на канал [**https://t.me/VoltLeger**](https://t.me/VoltLeger).

### 3. 🚗 Всегда актуальный пробег и счётчик домашней сети
* При запуске зарядки в любом месте (быстрая DC, медленная AC или домашняя) поле одометра предзаполняется последним введённым значением пробега с возможностью ручного редактирования.
* Счётчик домашней электроэнергии автоматически подставляет предыдущее зафиксированное показание.

## 🏷️ Тег для публикации на GitHub

Для создания нового релиза в GitHub используйте тег:

```bash
v2.5.4
```

> **Автоматическая сборка:** При пуше тега `v2.5.4` сработает GitHub Actions workflow (`.github/workflows/build-and-release.yml`), который скомпилирует APK и прикрепит готовый файл **`VoltLedger-v2.5.4-debug.apk`** прямо к релизу на GitHub.

### Команды Git для быстрой публикации:

```bash
# 1. Зафиксировать все изменения
git add .
git commit -m "Release v2.5.4: fix charging dialog input reset & outside dismissal, add Telegram channel in user profile and settings, bump version to 2.5.4"

# 2. Создать тег новой версии
git tag v2.5.4

# 3. Отправить ветку и тег на GitHub
git push origin main --tags
```
