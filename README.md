# VoltLedger ⚡ (v2.5.7)

**VoltLedger** — интуитивный, производительный и автономный журнал учёта зарядок и расходов для владельцев электромобилей (EV), разработанный на Jetpack Compose и Material Design 3.

---

## 🚀 Что нового в версии 2.5.7

### 1. 🛡️ Полная защита всплывающих окон старта зарядок от сброса при повороте экрана
* **Надёжная фиксация выбранной станции:** Устранена проблема, при которой выбранная станция (оператор) сбрасывалась на первый элемент списка при смене ориентации телефона или перезагрузке списка тарифов. Идентификатор выбранной станции сохраняется в `rememberSaveable` и восстанавливается мгновенно.
* **Исключена автоочистка ячеек во время работы:** Поля остатка заряда (`%`), текущего одометра (`км`), показаний электросчётчика (`кВт·ч`) и тарифа больше не затираются фоновыми процессами. Если пользователь начал ввод или отредактировал ячейку, система ждёт его действий и ничего автоматически не перезаписывает.
* **Сохранение открытого состояния диалогов:** Все всплывающие окна («Домашняя зарядка», «Редактирование зарядки», «Паспорт автомобиля», «Добавить расход», диалоги подтверждения удаления и импорта) при повороте телефона не схлопываются, а сохраняются в открытом виде вместе со всеми введёнными символами.

### 2. 🔒 Закрытие окон исключительно по воле пользователя
* Во всех диалогах активирована строгая защита от случайного закрытия (`dismissOnClickOutside = false`).
* Случайный тап пальцем мимо окна больше никогда не закрывает форму и не уничтожает введённые данные. Окно закрывается только по нажатию кнопки «Отмена», системной кнопки «Назад» или при подтверждении («Запустить» / «Сохранить»).

### 3. ☀️ Светлая тема и стили визиток (Postcard Color Themes)
* Полноценная светлая тема оформления с контрастными границами и высокой читаемостью под ярким солнцем.
* 4 фирменных темы оформления в настройках: «Эко Изумруд», «Закатный Драйв», «Глубокий Космос» и «Кибер Неон».

## 🏷️ Публикация релиза на GitHub

Текущая версия приложения: **`v2.5.7`** (код сборки `versionCode = 22`).

Для публикации нового релиза используйте тег:

```bash
v2.5.7
```

> **Автоматическая сборка APK:** При отправке (пуше) тега `v2.5.7` автоматически запускается GitHub Actions workflow (`.github/workflows/build-and-release.yml`), собирает APK и прикрепляет файл **`VoltLedger-v2.5.7.apk`** к релизу на GitHub.

### Команды Git для быстрой публикации:

```bash
# 1. Зафиксировать все изменения
git add .
git commit -m "Release v2.5.7: Fix charging dialog reset on rotation & station selection, prevent auto-clearing cells"

# 2. Создать тег новой версии
git tag v2.5.7

# 3. Отправить изменения и тег в репозиторий GitHub
git push origin main --tags
```
