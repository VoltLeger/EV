# VoltLedger ⚡ (v2.2.1)

**VoltLedger** — интуитивный, производительный и автономный журнал учета зарядок и расходов для владельцев электромобилей (EV), разработанный на Jetpack Compose и Material Design 3.

---

## 🚀 Что нового в версии 2.2.1

1. **Новый кинематографичный экран загрузки (Splash Screen):**
   * Реалистичный пейзаж электромобиля на закатной прибрежной трассе.
   * Фирменный технологичный логотип VoltLedger с неоновой бирюзовой молнией (`Electric Cyan`).
   * Неоновые шлейфы энергии и лаконичный индикатор загрузки с обновлённым слоганом: *«Учёт заряда, расхода и прогноз пробега EV»*.

2. **Реальное прикрепление файла резервной копии к E-mail:**
   * Полностью переработана логика отправки резервной копии: вместо текстового сообщения используется защищённый `ACTION_SEND` с `FileProvider` и `EXTRA_STREAM`.
   * При нажатии на кнопку приложение мгновенно создаёт актуальный файл `voltledger_backup_*.json` и физически прикрепляет его во вложение письма.

3. **Решение проблемы обновления и ускорение установки APK:**
   * **Устранён конфликт подписей:** Android требовал удалять старую версию из-за несовпадения сертификатов подписи при пересборке. Файл `debug.keystore` зафиксирован в репозитории с постоянным сертификатом, а GitHub Actions настроен на строгое использование постоянного ключа. Все будущие обновления устанавливаются прямо поверх предыдущих!
   * **Быстрая установка:** Удалены лишние тяжелые библиотеки Firebase (AI, Recaptcha, AppCheck), что в разы сократило количество DEX-файлов и время работы компилятора Android ART (`dex2oat`) при инсталляции.

4. **Полное удаление лишнего кода (GitHub Gist):**
   * Полностью удален сервис `GitHubBackupService.kt`, формы ввода токенов GitHub PAT и лишние сетевые модули.
   * Управление данными стало предельно понятным: сохранение на **Google Диск в 1 клик**, резервная копия на **E-mail** с файлом во вложении, а также нативный экспорт/импорт JSON и CSV.

5. **Актуализация версий:**
   * `versionCode = 7`, `versionName = "2.2.1"`.

## 🏷️ Тег для публикации на GitHub

Для создания нового релиза в GitHub используйте тег:

```bash
v2.2.1
```

> **Автоматическая сборка:** При пуше тега `v2.2.1` сработает GitHub Actions workflow (`.github/workflows/build-and-release.yml`), который скомпилирует APK и прикрепит готовый файл **`VoltLedger-v2.2.1-debug.apk`** прямо к релизу на GitHub.

### Команды Git для быстрой публикации:

```bash
# 1. Зафиксировать все изменения
git add .
git commit -m "Release v2.2.1: new splash screen, email backup attachment fix, keystore & install speed optimization, remove unused gist code"

# 2. Создать тег новой версии
git tag v2.2.1

# 3. Отправить ветку и тег на GitHub
git push origin main --tags
```

## 📱 Ключевые возможности приложения

* 🔋 **Двухэтапный учет сессий:** Быстрый запуск сессии при подключении к станции или домашней розетке, и точное завершение с учетом отданной энергии, показаний счётчика, потерь на зарядку и стоимости.
* ⚡ **Операторы и ночные тарифы:** Поддержка операторов Malanka, BatteryFly, Evika, Fora, домашней розетки и кастомных сетей. Автоматическое применение льготных ночных тарифов.
* ⏱️ **Учёт штрафов и платного простоя:** Расчет стоимости превышения лимита времени нахождения на ЭЗС.
* 📊 **Глубокая аналитика:** Стоимость 100 км пробега, сравнение реального расхода с паспортным WLTP, динамика затрат по месяцам.
* 💾 **Резервное копирование:** Сохранение на Google Диск в 1 клик, отправка бэкапа на E-mail файлом, экспорт/импорт JSON и CSV.
* 🔒 **Безопасность:** Защита входа PIN-кодом и биометрией.
