# Журнал изменений (Changelog) — VoltLedger ⚡

Все заметные изменения в проекте VoltLedger фиксируются в этом файле.  
Формат основан на стандартах [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и придерживается [Семантического версионирования (SemVer)](https://semver.org/lang/ru/).

## [2.5.9] — 2026-10-18

### 🚀 Автоматическое обновление приложения из GitHub (VoltLeger/EV)
- **Встроенная проверка обновлений напрямую из репозитория:**
  - Интегрирована прямая проверка релизов через официальный GitHub API (`https://api.github.com/repos/VoltLeger/EV/releases/latest`).
  - Приложение сравнивает установленную версию `v2.5.9` с последним релизом на GitHub.
  - Добавлена карточка «Обновления приложения» в разделе «Данные» с возможностью ручной проверки и ссылкой на GitHub.
- **Внутриаппная самозагрузка и запуск установщика APK:**
  - Скачивание APK-файла (`VoltLedger-v*.apk`) с отображением живого прогресс-бара, процентов и загруженных мегабайт.
  - Автоматический вызов системного установщика пакетов Android через защищённый `FileProvider` по завершении загрузки.
  - Добавлены разрешения `INTERNET` и `REQUEST_INSTALL_PACKAGES` для бесшовной установки.
- **Автоматическая проверка обновлений при открытии:**
  - Настройка «Проверять обновления при запуске» (включена по умолчанию).
  - При обнаружении нового релиза на главном экране появляется плашка с возможностью обновиться в 1 клик.
- **Динамический CI/CD релиз в GitHub Actions:**
  - В файле `.github/workflows/build-and-release.yml` настроено автоматическое извлечение версии из `build.gradle.kts` при пуше в ветку `main`.

### 📱 Полная изоляция строк и данных во всех вкладках настроек
- Во всех переключателях домашних тарифов, операторов и тем оформления текстовые блоки получили строгий вес `weight(1f)` с безопасным отступом `padding(end = 12.dp)`, полностью исключая наложение на элементы управления.
- Строки заголовков и кнопок в карточке редактирования авто изолированы для стабильного отображения на любых размерах экранов и масштабах шрифта.
- Обновлён `versionCode` до 24 и `versionName` до 2.5.9.

## [2.5.8] — 2026-10-18

### 📱 Полное разделение строк и данных в «Настройках» (исключение любых наложений)
- **Строгое зонирование и независимость элементов в строках меню:**
  - Во всех переключателях (автоматический ночной тариф, умные уведомления, отчёты, напоминания) текстовые описания переведены в отдельную колонку с `Modifier.weight(1f)` и отступом справа `12.dp`. Элементы управления (Switch, кнопки) зафиксированы на правом краю и физически не могут накладываться на текст.
  - Добавлены пояснительные подписи к каждому пункту уведомлений для кристальной ясности.
  - Между строками настроек внедрены чёткие разделители `HorizontalDivider` с вертикальными отступами.
- **Оптимизация верхних вкладок меню:**
  - Наименования 4 вкладок приведены к строгому лаконичному формату: «Гараж», «Тарифы», «Система», «Данные» (устранено переполнение от длинного текста «Данные и Автор»).
  - Каждая вкладка оформлена в изолированную капсулу с собственной рамкой, подсветкой и безопасным расстоянием.
  - Внутренний контейнер `LazyColumn` переведён на `weight(1f)`, исключая взаимное наложение контента со списком вкладок.
- **Структурированное отображение параметров электромобилей:**
  - Строки списка авто переработаны: ёмкость батареи, пробег и остаток заряда (%) разделены на чёткие информационные блоки с точечными разделителями и контрастными акцентными цветами.
- **Обновление сборки до v2.5.8 (код версии 23):**
  - Обновлён `versionCode` для чистого обновления поверх существующей версии на устройствах.

## [2.5.7] — 2026-10-17

### 🎨 Исправление отображения настроек (устранение наложения строк)
- **Исправление макета `VoltCard`:**
  - В базовом компоненте карточек `VoltCard` добавлен внутренний `ColumnScope` и вертикальный контейнер `Column`.
  - Устранена критическая проблема в экране «Настройки», при которой все строки, селекторы валют, языков, тем оформления и карточки накладывались друг на друга («все строчки сбились и отображались одно на одном»).

### 🔄 Динамическое отображение версии приложения
- **Привязка к `BuildConfig.VERSION_NAME`:**
  - Версия приложения в футере «Настроек», на заставке и в диалоге «О разработчике» теперь динамически считывается из `BuildConfig.VERSION_NAME`.
  - Больше нет рассинхронизации версий: при каждом новом релизе и обновлении `versionName` в Gradle номер версии обновляется автоматически во всех экранах приложения (сейчас `v2.5.7`).

### ⚡ Главный экран: чистый расчёт среднего расхода и обновлённая нижняя сводка
- **Очистка окна «Средний расход»:**
  - Убран мелкий и перегруженный пояснительный текст («Поездка: X км • Расход: Y кВт·ч»).
  - Реализован строгий и понятный расчёт: средний расход рассчитывается строго за последние 3 зарядки, либо за 2 последние зарядки, если пробег между ними превышает 200 км.
- **Обновление нижнего виджета метрик (3 колонки):**
  - **Колонка 1:** «ПРОБЕГ / МЕСЯЦ» — суммарный пробег за все зарядки в текущем календарном месяце.
  - **Колонка 2:** «ПОСЛ. ЗАРЯДКА» — объём энергии и стоимость последней завершённой зарядки.
  - **Колонка 3:** «ЦЕНА / 100 КМ» — стоимость 100 км пробега в текущем месяце в выбранной основной валюте.

### 🛡️ Устранение сброса данных и выбор станций при смене ориентации экрана
- **Фиксация выбранной станции в `StartChargingScreen`:**
  - Устранена ошибка, при которой выбор оператора или тарифа сбрасывался на первый элемент списка при смене ориентации телефона или перезагрузке списка из локальной базы данных.
  - Сохранение `selectedOperatorId` через `rememberSaveable` гарантирует стабильность выбора даже в момент асинхронного обновления Flow.
- **Исключение автоматического очищения ячеек ввода:**
  - Поля «Остаток заряда (%)», «Пробег (км)», «Показания счётчика (кВт·ч)» и тариф надёжно изолированы. Система ждёт действий пользователя и не очищает набранные значения.
- **Закрытие всплывающих окон исключительно пользователем:**
  - Для всех диалоговых окон в приложении активирован режим `dismissOnClickOutside = false`. Случайные клики по экрану мимо диалога больше не закрывают окно и не сбрасывают введённые данные.
  - Окна закрываются только по нажатию кнопок «Отмена», «Закрыть», системной кнопки «Назад» или при подтверждении операции.
- **Сохранение открытых окон при смене ориентации:**
  - Диалоги «Редактирование зарядки», «Паспорт автомобиля», «Добавить расход» и подтверждения удаления привязаны к сохраняемым ID сущностей и не закрываются при повороте экрана.

## [2.5.3] — 2026-10-02

### 🚗 Сквозной учёт пробега (одометра) и показаний счётчика
- **Сквозная подстановка последнего пробега при старте любой зарядки:**
  - В экране `StartChargingScreen` поле ввода одометра теперь надёжно предзаполняется самым последним введённым значением пробега автомобиля. Пользователю больше не нужно вводить пробег с нуля.
  - В диалоге «Домашняя зарядка» на Главном экране добавлено поле текущего пробега автомобиля, также предзаполненное последним одометром.
  - Пользователь сохраняет полный контроль и может скорректировать цифру вручную при необходимости.
- **Автоматическая подстановка последнего показания счётчика в домашней зарядке:**
  - Поле показаний электросчётчика теперь по умолчанию предзаполняется последним сохранённым значением.
  - При завершении домашней зарядки конечное показание фиксируется и сохраняется как база для следующего сеанса.
- **Надёжная фиксация пробега в истории и профиле авто:**
  - При завершении сессии (`FinishChargingScreen`) одометр сохраняется непосредственно в запись сессии и обновляет пробег автомобиля на Главном экране.
  - При редактировании сессий или добавлении расходов пробег автомобиля моментально синхронизируется.

### 📊 Бесшовный расчёт среднего расхода месяца
- Предотвращено обнуление виджета среднего расхода при наступлении нового календарного месяца: приложение плавно использует проверенный показатель прошлого месяца с корректной маркировкой, пока не накопятся две зарядки в текущем месяце.

## [2.3.1] — 2026-09-24

### ⚡ Домашняя зарядка и дифференцированные тарифы
- **Быстрое переключение тарифов в окне домашней зарядки:**
  - В верхней части окна «Домашняя зарядка» добавлены 3 удобные кнопки выбора тарифа: **«Стандарт»** (всегда доступен), **«2-зонный»** (день/ночь) и **«3-зонный»** (пик/полупик/ночь).
  - При переключении тариф моментально пересчитывается, обновляется стоимость до 100% батареи и сохраняется в параметрах сессии.
- **Индивидуальный учёт и автоподстановка показаний домашнего счётчика:**
  - Показания счётчика домашней электроэнергии сохраняются отдельно в постоянное хранилище настроек (`DataStore`).
  - При открытии окна зарядки поле счётчика автоматически предлагает предыдущее сохранённое значение в виде интерактивной подсказки в один клик.
- **Интерактивная настройка тарифов домашней сети:**
  - Добавлен отдельный блок управления тарифами в Настройках: стандартный одноставочный, двухтарифный (день/ночь), трёхтарифный дифференцированный.
  - Установлены удобные базовые значения цен и интервалов:
    - Стандартный тариф: `0.36` руб./кВт·ч.
    - Ночной (минимальных нагрузок): с 23:00 до 06:00 — `0.1822` руб./кВт·ч.
    - Полупиковый: с 06:00 до 17:00 — `0.2126` руб./кВт·ч.
    - Пиковый (максимальных нагрузок): с 17:00 до 23:00 — `0.5467` руб./кВт·ч.
  - Автоматическое определение периода суток по системному времени устройства при запуске зарядки с подсказкой действующего тарифа и ориентировочной суммы.
  - При первом нажатии на «Домашняя зарядка», если тарифы ещё не настроены пользователем, выводится диалоговое предупреждение с предложением перейти в Настройки либо продолжить со стандартным тарифом.

### 🚗 Учёт и отображение пробега (Одометр)
- **Ввод текущего пробега при завершении зарядки:** В диалоговом окне / экране завершения сессии добавлено поле одометра автомобиля.
- **Динамический актуальный пробег на главном экране:** В шапке главного экрана сверху отображается самый свежий пробег автомобиля, который автоматически актуализируется после каждой завершённой зарядки и после внесения любых расходов/услуг.

### 🧹 Очистка кодовой базы и оптимизация
- Полностью удалён неиспользуемый код PIN-кодов и биометрической аутентификации (`BiometricHelper`, зависимости `biometric-ktx`), облегчив размер сборки и убрав лишние фоновые процессы.
- Оптимизировано сохранение в DataStore и реактивные потоки ViewModel.
- Подготовлена стабильная сборка к релизу `v2.3.1` (versionCode 9).

### 🌟 Загрузочный экран (Splash Screen)
- **Новый кинематографичный Splash Screen по утверждённому макету:**
  - Реалистичный фон с современным кроссовером EV на прибрежной живописной трассе на закате.
  - Фирменный логотип VoltLedger с белым крылом и светящейся неоновой молнией цвета Electric Cyan.
  - Обновлённый слоган: *«Учёт заряда, расхода и прогноз пробега EV»*.
  - Плавный горизонтальный капсульный индикатор загрузки с аккуратной надписью *«ЗАГРУЗКА...»*.
  - Декоративные диагональные бирюзовые неоновые световые шлейфы в нижних углах экрана.

### ✉️ Резервное копирование и E-mail
- **Настоящее прикрепление файла резервной копии к письму:**
  - Полностью переработан механизм отправки резервной копии на e-mail: вместо текстового `ACTION_SENDTO` реализован защищённый `ACTION_SEND` с генерацией реального файла `voltledger_backup_*.json` во вложении через `FileProvider` и `EXTRA_STREAM`.
  - Почтовый клиент (Gmail, Яндекс.Почта, Mail.ru, Outlook) открывается с уже заполненным адресатом, темой, подробной инструкцией и прикреплённым JSON-файлом.

### ⚡ Производительность и решение конфликтов установки
- **Устранение конфликта подписей при обновлении:**
  - Устранена системная ошибка Android *«Приложение не установлено, так как оно конфликтует с другим пакетом»* (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`).
  - Файл `debug.keystore` исключён из `.gitignore`, зафиксирован в репозитории с постоянным криптографическим отпечатком сертификата, а пайплайн GitHub Actions (`build-and-release.yml`) обновлён для строгого использования единого постоянного ключа. Все последующие обновления теперь устанавливаются поверх предыдущих версий без необходимости переустановки.
- **Мгновенная установка APK на смартфон:**
  - Из `build.gradle.kts` удалены неиспользуемые тяжелые зависимости Firebase (Firebase AI, AppCheck Recaptcha, AppCheck Debug), создававшие избыточные 11 DEX-файлов и более 70 МБ служебного кода.
  - Количество DEX-файлов и время верификации Android ART (`dex2oat`) сокращены в разы, благодаря чему установка приложения на телефон теперь происходит за пару секунд.

### 🧹 Удаление неиспользуемого кода (GitHub Gist)
- Полностью удален сервис `GitHubBackupService.kt`, диалоги ввода персонального токена GitHub PAT, диалог восстановления по Gist ID и связанные методы в ViewModel/MainActivity.
- Основной акцент сделан на простые и надёжные методы: Google Диск (1 клик), E-mail с файлом вложения и экспорт/импорт JSON/CSV.
